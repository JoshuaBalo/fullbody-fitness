About FullBody Fitness

FullBody Fitness is a simple exercise finder. Search for a movement by name or muscle group, read what it works and how to do it, save the ones you like, and turn them into a routine you can actually follow.

It was built as a course project for CSCI 2170 at Dalhousie University, because most fitness apps are cluttered with accounts, ads and paywalls before you even see a single exercise. This one does the opposite: open the page, search, and start moving.

1. Search

Type a movement like "Press" or "Squat", or a muscle group like "Chest" or "Legs". Results filter as you type.

2. Learn and save

Tap Details for the description, muscles worked and equipment needed. Tap Favourite to keep it for later.

3. Build a routine

Add favourites to a routine, set your sets, reps and rest, save it, then start the workout and check exercises off as you go.

Built with

  • HTML, CSS and vanilla JavaScript
  • Bootstrap 5.3.3
  • wger Workout Manager REST API for exercise data, images, muscles and equipment
  • Browser storage (localStorage) for favourites, routines and drafts, no account needed

A note on the data

Exercise names, descriptions, photos and muscle data come from wger. Some exercises have no photo, so a placeholder is shown instead, and some descriptions are short because that is all the source provides.

This app gives general exercise information. It is not medical advice and it does not replace a coach, trainer or health professional. Start light, use good form, and stop if something hurts.
